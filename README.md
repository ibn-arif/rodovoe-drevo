# Родовое древо

Сайт, где семья вместе собирает своё родовое древо: создатель получает ссылку, отправляет её родне,
каждый дописывает тех, кого знает, и нажимает «Сохранить». Создатель видит историю правок и может
откатить любую из них. Древо можно скачать плакатом в PDF — четыре дизайна, от A4 до A0.

Пример: [Романовы, 1613–1917](https://ibn-arif.github.io/rodovoe-drevo/tree.html#t=romanovy).

## Как устроено

- Статические страницы без сборки (`index.html`, `tree.html`, `js/`, `css/`), d3 для древа,
  jsPDF + svg2pdf.js для PDF, шрифт PT Serif (с буквой Ӏ) встраивается в файл.
- Данные — в Supabase. Таблицы закрыты; сайт вызывает только функции Postgres из
  `supabase/schema.sql`, и они проверяют права по ссылке.
- Три ссылки на древо: создателя (всё, включая откат), для родни (дописывать, исправлять, удалять),
  для просмотра. Ссылки родни и просмотра выводятся из ссылки создателя; в базе хранятся только хэши.

## Разработка

```bash
npm install
npm test            # модель, база (PGlite), страницы (Playwright + установленный Chrome)
python3 -m http.server 4173   # открыть http://localhost:4173/
```

Применить схему к Supabase (строку подключения не коммитить):

```bash
SUPABASE_DB_URL='postgresql://…' node scripts/apply-sql.mjs supabase/schema.sql supabase/example.sql
```

Пример пересобирается из `data/romanov.json`: `node scripts/build-example.mjs`.
